# Curated header logos

Static marketplace assets here are separate from generated screenshot previews in `../plugins/`. Registry `headerLogo` accepts local PNG paths in this directory. Preview images and `previewKind` remain independent; use `screenshot` (or omit the kind) when replacing a brand preview with a native screenshot.

`gaugedb.png` is the unchanged GaugeDB brand mark from `preview.png` at [approved commit 0c6ce326582dc26b408cc1356bbb7424f1eaa0a1](https://github.com/dyd4dsh7/gaugedb-omarchy/blob/0c6ce326582dc26b408cc1356bbb7424f1eaa0a1/preview.png).
